Dockerize and deploy any app, verified rather than vibes.

vibe-ship detects your stack from the repo and writes a hardened Dockerfile, docker-compose, CI/CD pipeline, and Kubernetes or cloud config. It then checks everything with a 93-rule auditor and a real Docker build before handing it over.

What vibe-ship generates

Dockerfile

Multi-stage, pinned, cache-mounted, non-root, with a healthcheck that actually runs in the final image.

docker-compose

Your app plus Postgres, MySQL, MongoDB, Redis, RabbitMQ or Kafka, with readiness-gated startup, a migration job, volumes and limits.

CI/CD pipeline

GitHub Actions or GitLab CI: test, build, Trivy scan, SBOM, provenance, cosign signing, deploy. Actions pinned to SHAs.

Deploy config

Kubernetes, Fly.io, Render, Railway, Heroku, Cloud Run, AWS, Azure, Kamal, or any VPS with automatic HTTPS via Caddy.

How it works

  1. Detect. A deterministic script reads manifests and lockfiles: framework, declared runtime version, port, entrypoint, health route, databases from real dependency names, and the env vars your code reads.
  2. Generate. Tested per-stack templates are adapted to what was detected. Existing deployment files are audited instead of overwritten.
  3. Harden. Every GitHub Action gets pinned to a commit SHA, and the auditor runs on the output until nothing at MEDIUM or above remains.
  4. Prove. With Docker available, it builds, starts, waits for healthy, curls the health endpoint, confirms a non-root UID, and cleans up.

FAQ

What is vibe-ship?

A free, open-source Claude Code skill that turns any codebase into a deployable application. It detects the stack, writes a hardened Dockerfile, docker-compose, CI/CD pipeline and platform config, and verifies them with a 93-rule static auditor and real Docker builds.

Does it overwrite my existing Dockerfile?

No. Existing deployment files are audited and scored, then fixed in place with your approval. Application code is never changed without asking.

Do I need Docker installed?

Not for generating files or auditing. With Docker installed, vibe-ship also builds and health-checks the result.

Can I use the auditor without Claude?

Yes. Run python3 scripts/audit.py --path . anywhere with Python 3.8+, or use the sudais-khalid/vibe-ship@v2 GitHub Action.

Where can it deploy?

Any VPS (Compose + Caddy), Kamal, Fly.io, Render, Railway, Heroku, DigitalOcean App Platform, Google Cloud Run, AWS App Runner and ECS Fargate, Azure Container Apps, and Kubernetes.
